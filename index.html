Como funcionam os códigos Roblox?

Muitos jogos de Roblox dão códigos com recompensas grátis, como moedas, EXP a dobrar, rodadas ou decorações. Cada código só funciona dentro do seu jogo, e a maioria expira passado algum tempo. Abre a página do jogo para veres os passos para usar os códigos.
